# CompliVerge
Static site for **CompliVerge** (https://compliverge.com) — a business compliance tracker.
Served by GitHub Pages from `main` (root). Custom domain via `CNAME`; `.nojekyll` serves files as-is.
SEO: `robots.txt`, `sitemap.xml`, structured data in `index.html`. The only embedded key is the public
Supabase anon key (safe); no secrets are in this repo.
